# 09 - Identidade visual inicial

## Direcao

A primeira identidade do ChaveRadar deve transmitir confianca, tecnologia e simplicidade sem parecer um sistema imobiliario pesado ou um CRM antigo.

### Paleta inicial

- Azul-marinho profundo: `#132238`
- Azul quase preto: `#0D1B2A`
- Verde-petroleo: `#0F766E`
- Verde suave: `#DFF5F1`
- Fundo claro: `#F5F7F9`
- Texto principal: `#16202C`

### Logo v0.2.0

Marca minimalista vetorial composta por um radar circular e um ponteiro que lembra uma chave/seta. O wordmark usa `ChaveRadar`, destacando `Radar` no verde-petroleo.

A marca esta implementada em SVG diretamente no template para evitar dependencia externa durante o MVP. Pode ser redesenhada posteriormente sem alterar a estrutura do sistema.

### Referencias de experiencia

- Pipedrive: leitura rapida de metricas, dados comerciais e navegacao direta.
- Linear: interface calma, consistente, sidebar discreta e conteudo principal em destaque.

Estas referencias servem somente para orientar principios de usabilidade e nao para copiar layout, marca ou elementos proprietarios.
