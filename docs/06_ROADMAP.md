# 06 - Roadmap

## MVP 1

1. Executar a base Django localmente.
2. Criar cadastro de perfis monitorados.
3. Criar cadastro/contexto de publicações e imóveis.
4. Criar tela de importacao: colar, CSV e Excel.
5. Implementar deduplicacao.
6. Implementar classificação por regras.
7. Adicionar IA apenas para casos ambiguos.
8. Criar tela de revisão.
9. Criar dashboard e filtros.
10. Exportar Excel.
11. Autenticacao basica, cadastro e aprovacao administrativa. **Implementado na v0.2.3.**

## MVP 2

1. Integracao oficial Meta.
2. Backfill inicial.
3. Coleta incremental.
4. Cobertura e auditoria por perfil.

## MVP 3

1. Webhooks quando houver infraestrutura adequada.
2. Provedor licenciado para fontes adicionais.
3. Evoluir autenticacao para papeis/permissoes granulares, recuperacao de senha e auditoria completa.
4. Integracao CRM.
5. PWA completa e, se necessário, app Android nativo.

12. Aprovacao em massa na fila de revisao com selecao multipla. **Implementado na v0.2.4.**
